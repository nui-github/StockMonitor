# 10 — Compliance, ลิขสิทธิ์ และ Disclaimer

> เอกสารนี้เป็นแนวปฏิบัติทางวิศวกรรม **ไม่ใช่คำแนะนำทางกฎหมาย**
> ก่อนเปิดสาธารณะ/หารายได้ ควรให้ทนายที่เชี่ยวชาญด้านตลาดทุนไทยตรวจอีกครั้ง

## 1. จุดยืนของผลิตภัณฑ์

**เว็บนี้เป็นเครื่องมือรวบรวมข้อมูลและวิเคราะห์เพื่อการศึกษา ไม่ใช่ผู้แนะนำการลงทุน**

ผลกระทบต่อการออกแบบ:
- ❌ ไม่มีคำว่า "ควรซื้อ" / "ควรขาย" / "แนะนำถือ" ใน output
- ❌ ไม่มีราคาเป้าหมายที่นำเสนอเป็นคำแนะนำ
- ❌ ไม่ผูกคำแนะนำกับพอร์ต/โปรไฟล์ความเสี่ยงของผู้ใช้รายบุคคล
- ✅ นำเสนอเป็น "มุมมองฝั่งบวก / ฝั่งลบ / ความเสี่ยง / สิ่งที่ต้องติดตาม"
- ✅ แสดงระดับความมั่นใจ (confidence) และช่องว่างข้อมูล (dataGaps) ทุกครั้ง

> ในไทย การให้คำแนะนำการลงทุนเป็นกิจการที่ต้องได้รับใบอนุญาต/ขึ้นทะเบียนกับ ก.ล.ต.
> การอยู่ในฝั่ง "ข้อมูลและการวิเคราะห์ทั่วไป" คือเหตุผลของข้อบังคับด้านบน

## 2. Disclaimer ที่ต้องแสดง

**บังคับแสดงทุกหน้าที่มีบทวิเคราะห์ AI** (component `DisclaimerBar`)

```
ข้อมูลและบทวิเคราะห์บนเว็บไซต์นี้จัดทำโดยระบบอัตโนมัติเพื่อการศึกษาเท่านั้น
ไม่ถือเป็นคำแนะนำการลงทุน การเสนอขาย หรือการชักชวนให้ซื้อขายหลักทรัพย์ใด ๆ
ราคาอาจล่าช้าหรือคลาดเคลื่อน ผู้ใช้ควรตรวจสอบข้อมูลจากแหล่งต้นทางและ
ปรึกษาผู้แนะนำการลงทุนที่ได้รับใบอนุญาตก่อนตัดสินใจ
การลงทุนมีความเสี่ยง ผู้ลงทุนควรศึกษาข้อมูลก่อนตัดสินใจลงทุน
```

เพิ่มเติมที่ต้องแสดง:
- ป้าย **"สร้างโดย AI"** บนทุกบทวิเคราะห์ พร้อมเวลาที่สร้าง
- ป้าย **"ข้อมูลล่าช้า X นาที"** เมื่อราคาไม่ใช่ realtime
- หน้า `/disclaimer` เต็ม + ลิงก์จาก footer ทุกหน้า

## 3. ลิขสิทธิ์ข่าว — กฎเหล็ก

| ทำได้ | ห้ามทำ |
|-------|--------|
| เก็บ+แสดง หัวข้อ, URL, ชื่อแหล่ง, เวลา, รูป thumbnail จาก OG (ถ้าอนุญาต) | แสดงเนื้อข่าวเต็มบนเว็บเรา |
| เขียนสรุปใหม่ด้วยคำของเรา/ระบบ | ตัดลอกย่อหน้าจากต้นฉบับ |
| เก็บ full text ไว้ในระบบเพื่อสังเคราะห์ (ไม่เผยแพร่) | เปิด endpoint ให้ดึง full text ออกไป |
| อ้างอิงสั้น ๆ ≤ 15 คำ ในเครื่องหมายคำพูด + ระบุแหล่ง | อ้างยาว หรือหลาย quote จากบทความเดียว |
| ลิงก์ออกไปหน้าต้นฉบับเสมอ | ทำ reader mode / mirror / AMP ของเขา |

**บังคับในโค้ด**
- `summaryTh` ต้องมาจาก LLM ที่ถูกสั่งให้เรียบเรียงใหม่ + ตรวจ n-gram overlap กับต้นฉบับ (ถ้า 8-gram ซ้ำ → regenerate)
- `NewsItem` ทุกอันต้องมี `SourceBadge` + ลิงก์ `target="_blank" rel="noopener nofollow"`
- API `/api/v1/news` **ไม่คืน** field เนื้อหาเต็ม

**การ crawl**
- เคารพ `robots.txt` (ใช้ตัวเช็คก่อน fetch)
- User-Agent ระบุตัวตน + URL ติดต่อ
- rate limit ต่อโดเมน (≤ 1 req/2s), backoff เมื่อ 429/503
- ถ้าแหล่งไหนมี API/licence ให้ใช้ทางนั้นแทน crawl

## 4. ข้อมูลราคา (market data licence)

- ตรวจ ToS ของแต่ละ provider เรื่อง **redistribution** ก่อนแสดงต่อสาธารณะ — free tier หลายเจ้าอนุญาตแค่ใช้ภายใน
- ห้ามใช้ endpoint ที่ไม่เป็นทางการ (เช่น scrape Yahoo) ใน production
- SET/หุ้นไทย: ต้องมีสัญญากับผู้มีสิทธิ์ ดู [docs/03 §2](03-DATA-SOURCES.md)
- แสดงเครดิตผู้ให้บริการข้อมูลตามที่สัญญากำหนด (footer หรือหน้า `/about`)

## 5. ข้อมูลส่วนบุคคล (PDPA)

- เก็บเท่าที่จำเป็น: email, ชื่อแสดงผล, watchlist, alert
- **ไม่เก็บ**: เลขบัญชี, ข้อมูลโบรกเกอร์, ตัวเลขพอร์ตจริง (ถ้าทำ portfolio ให้ผู้ใช้กรอกเองและเก็บแบบไม่ผูกตัวตนได้ยิ่งดี)
- หน้า `/privacy` ระบุ: เก็บอะไร, ทำไม, เก็บนานเท่าไร, แชร์กับใคร (provider/AI), สิทธิของเจ้าของข้อมูล
- มีช่องทางขอลบบัญชี + ลบข้อมูลจริงภายใน 30 วัน
- cookie: ใช้เท่าที่จำเป็น (session) — ถ้าเพิ่ม analytics ต้องมี consent banner ที่ default = ปฏิเสธ
- ข้อมูลผู้ใช้ **ห้าม** ส่งเข้า prompt ของ AI โดยไม่จำเป็น

## 6. ความรับผิดชอบต่อ output ของ AI

- เก็บ `ai_reports` ทุกฉบับพร้อม `model`, `sourceIds`, `createdAt` → ตรวจสอบย้อนหลังได้
- มีปุ่ม "รายงานปัญหา" บนบทวิเคราะห์ → เก็บเข้า queue ให้คนตรวจ
- ถ้าตรวจพบบทวิเคราะห์ผิดร้ายแรง ต้องถอด/แทนที่ได้ทันที (flag `is_retracted`)
- ไม่ใช้ AI สร้างข้อความที่อ้างว่ามาจากบุคคล/องค์กรจริงโดยที่เขาไม่ได้พูด

## 7. Checklist ก่อนเปิดสาธารณะ

- [ ] `/disclaimer`, `/privacy`, `/terms` มีเนื้อหาจริง (ไม่ใช่ lorem) และลิงก์จาก footer
- [ ] `DisclaimerBar` แสดงบนทุกหน้าที่มีบทวิเคราะห์
- [ ] ป้าย "สร้างโดย AI" + timestamp บนทุก report
- [ ] ตรวจ ToS ของ provider ราคาทุกเจ้าเรื่อง redistribution แล้ว
- [ ] robots.txt checker ทำงานใน ingest pipeline
- [ ] n-gram overlap check ทำงานใน summary pipeline
- [ ] regex กันคำแนะนำซื้อขายทำงานใน verification layer
- [ ] มีช่องทางติดต่อ/รับเรื่องร้องเรียน (email ใน footer)
